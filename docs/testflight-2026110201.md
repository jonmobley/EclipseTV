# Eclipse build 2026110201 (iPhone and Apple TV)

Built from EclipseTV branch audit-fixes-2026-11-02 commit 75db050, on top of build 2026110102 (daf1f08). New since 2026110102, from the 2026-11-02 audit:

- iCloud Show sync: removing a card or surface and then undoing or re-adding it now holds. Removal markers carry a time (`id@ms`, `+id@ms`). Ship together with Mac test copy 180 or later, because older builds treat the new markers as unknown ids.
- Phone Camera: pairing refuses addresses outside the local network, and re-pairing stops the old stream first.

CamTailKit comes from CamTail commit fb8833b, the same as build 2026110102. The sibling eclipsepro packages are main commit 1fa0d20 plus the audit package fixes (eclipsepro branch audit-fixes-2026-11-02: EclipseSyncKit SyncTombstones, EclipsePhoneCameraProtocol local-host check). This release is for internal TestFlight testing.
