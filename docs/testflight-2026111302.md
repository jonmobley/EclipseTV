# Eclipse build 2026111302 (iPhone and iPad only)

Built from EclipseTV branch release/testflight-20261113-2, cut from fix/showlive-mutual-auth
(fcf830f), which sits on fix/appstore-1-0-prep. Everything in 2026111301 is kept.

Sibling packages, unchanged from 2026111301 in what the app uses: eclipsepro main 8403c60f
(LivePollKit, EclipsePhoneCameraClient; no package changes since 8dd92423), CamTail main
ac076aa (CamTailKit 1.8.0).

New since 2026111301:
- Show Live: joining needs proof of the same iCloud account (a per-account secret kept in
  iCloud Keychain), each join request is single-use, and both phones check each other right
  after connecting. The director drops any other device claiming to be director. Remote
  skip/seek/countdown values that aren't finite are ignored instead of crashing.
  All phones using Show Live must run this build or later.
- Mac remote: only connects to addresses on the local network.
- Crash reports: no session tracking (no per-install ID).

Not in this build: Apple TV (only its crash-report setting changed).
Not yet on main: all of the above (branches fix/appstore-1-0-prep, fix/showlive-mutual-auth).
