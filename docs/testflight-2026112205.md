# Eclipse build 2026112205 (iPhone and iPad)

Built from branch release/testflight-2026112205: everything in 2026112204
(main a2e0dcc plus Camera Mode, Camera Kit, Mac frame picks and odd-shaped screens)
plus branch feature/poll-editor (b1ba4d5). Not on main yet.

New since 2026112204:
- Polls are made and edited in the app; the website is no longer needed for it.
  - The poll list (+ → QuestPoll in a Show) has a + for a new poll and a pencil beside
    each poll. A poll written while choosing one for a Show is added to that Show.
  - A Show card's ⋯ has Edit Poll… (it used to open questpoll.com).
  - Swipe a poll in the list, or use Delete in the editor, to delete it. It warns when
    Show cards still use that poll.
  - Settings → QuestPoll → My Polls lists the account's polls for editing.
- The editor: name, Poll or Quiz, time per question, show the question on phones, and
  questions with two to five answers (a quiz marks the right one). Save stays off until
  the poll is complete and a line says what is missing.
- A poll that is live keeps the copy it started with; edits show on the next start.

Apple TV: no change; not uploaded.

Sibling packages (same as 2026112204): eclipsepro 5eae5a2b (branch
claude/camera-frames-ribbon), CamTail ac076aa.

Not checked before upload: a real save, edit or delete against questpoll.com (it has no
test copy); the screens were checked with sample data only. First real save is on device.
