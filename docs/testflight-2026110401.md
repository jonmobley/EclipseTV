# Eclipse build 2026110401 (iPhone and iPad only)

Built from EclipseTV branch claude/eloquent-wright-n6tkwf commit 3adf58c, merged with
75db050 (the sync Undo fix that shipped in 2026110201). Everything in 2026110201 is kept.
New since 2026110201:

- Landscape layouts: controls and text stay out of the notch (Media Library, See All,
  Albums, previews, note editor, countdown editor, QuestPoll host, LivePoll sign-in);
  the iCloud banner stays in the tile column, clears the Music button, is opaque, and
  the grid scrolls the last row clear of it; QuestPoll join QR sits beside its code;
  iPad landscape Home tiles are capped so Home fits on screen.
- Live tile outline is blue (system blue), matching the Eclipse Mac app. Locked stays amber.
- PTZ camera (CamTailKit / ObsbotControl) moves to CamTail commit 7fb2091 (branch
  remove-joystick, not yet on CamTail main), chosen by the owner: eased drags and pinch
  zoom, portrait-style controls in vertical mode, voice-control updates. Previous builds
  used fb8833b, which 7fb2091 contains.

The sibling eclipsepro packages are commit fedfcff6 (branch audit-fixes-2026-11-02), the
same as 2026110201; their Phone Camera local-network check is not yet on eclipsepro main.
No Apple TV build this time; the TV app is unchanged since 2026110201 and pairing is
unchanged. This release is for internal TestFlight testing.
