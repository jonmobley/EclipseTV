# Eclipse build 2026110402 (iPhone and iPad only)

Built from EclipseTV branch claude/eloquent-wright-n6tkwf commit f1219d8, merged with
75db050 (the sync Undo fix that shipped in 2026110201 and 2026110401). Everything in
2026110401 is kept. New since 2026110401:

- Website fullscreen: every website card of the open Show is a tab in a strip above the
  card (shown with two or more tabs); the TV follows the active tab. ⊕ opens a new tab by
  address. Windows a site opens (window.open, sign-in) are phone-only tabs with a Send to
  TV button, replacing the old pop-up sheet. Landscape buttons are Close · ⋯ · Refresh · ⊕,
  with Send to TV and Back only while they apply (Back hides until there is history).
  Phones keep the column beside the card; iPad gets a browser-style top bar (tabs left,
  buttons top right) in both orientations. The Vertical title bar gains Refresh and ⊕.
- iCloud banner ("Sign in to iCloud…") shows on Home only and has a × that remembers the
  dismissal per message.
- Simulator-only guard for the Camera tile teardown (no effect on devices).

The sibling eclipsepro packages are commit fedfcff6 (branch audit-fixes-2026-11-02), the
same as 2026110401 and 2026110201. PTZ camera (CamTailKit) is CamTail commit 7fb2091
(branch remove-joystick), the same as 2026110401. No Apple TV build this time; the TV app
is unchanged. This release is for internal TestFlight testing.
