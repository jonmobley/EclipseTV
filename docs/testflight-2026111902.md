# Eclipse build 2026111902 (iPhone and iPad)

Built from EclipseTV dad54cc (branch release/testflight-2026111902), which is build
2026111901 plus:
- Live preview (hero) takes pinch and drag directly: pinch zooms a live photo into a
  crop, one finger pans it, and the countdown clock can be resized and moved the same
  way. The corner button keeps its words (Fit / Fill) and becomes a reset arrow once
  something has been pinched or dragged; tapping it puts it back.
- Pinch/drag is off during Blackout hold (saving a crop re-sends the picture, and the
  TV must stay black), while output is locked, while following a director, and while
  a slideshow owns the hero.
- Not restored from the old branch: the whole-slideshow Fit / Fill toggle on the hero
  button (main removed it on purpose on 2026-11-10; the button flips the current slide).

Sibling packages unchanged: eclipsepro 9f8accd2, CamTail ac076aa (CamTailKit identical in the
checked-out 77a0c32).
Apple TV: no Apple TV code changed, so no new Apple TV build.
