# Eclipse build 2026110403 (iPhone and iPad only)

Built from EclipseTV branch claude/eloquent-wright-n6tkwf at 0d0cc68, merged with main
(13d1512, build 2026110402). Everything in 2026110402 is kept. New since 2026110402:

- Prompter: Add → Prompter puts a teleprompter tile in a Show. The operator view shows
  the script in the show's frame (16:9, or 9:16 in Vertical mode) with a reading guide,
  Play/Pause, Reset, a speed slider (0.25× to 3×), text size, drag to scrub, tap or Space
  to play, and a script editor. Go Live shows it on AirPlay/HDMI or the Practice hero (the
  Apple TV parks black, as with countdowns); the hero shows the current lines. The
  script syncs per Show through iCloud as its own private record (never shared with a
  Show), so it will follow between iPad and the Mac app once the Mac side ships.
- Splash: the launch screen and the fading splash show the eclipse glow alone on black;
  the rounded icon tile behind it is gone.
- Show grid: tile titles are left-aligned along the bottom of the card.
- Website browser: Auto Scroll button. Tap to turn on, tap the page to pause and resume,
  drag to pause; a floating speed slider sits over the page; long-press the button (or the
  ⋯ menu) for quick speed picks. It stops at the bottom and when the page or tab changes.

The sibling eclipsepro packages are commit fedfcff6 (branch audit-fixes-2026-11-02), the
same as 2026110402. PTZ camera (CamTailKit) is CamTail commit 7fb2091 (branch
remove-joystick), the same as 2026110402. No Apple TV build; the TV app is unchanged.

Owner step before relying on Prompter sync in this build: deploy the CloudKit schema
(record type `Prompter`) from Development to Production in the CloudKit Console for
container iCloud.com.mobleypro.eclipse.EclipseiPhone. Until then a TestFlight build keeps
scripts on the device and the sync save is dropped.
