# Eclipse build 2026112204 (iPhone and iPad)

Built from branch release/testflight-2026112204: everything in 2026112203
(main a2e0dcc plus Camera Mode, Camera Kit and Mac frame picks) plus one change from
branch claude/wall-screen-signal (6a1db79). Not on main yet.

New since 2026112203:
- Odd-shaped screens, for an LED wall behind an EDID box that reports its own size
  (for example 2048×768). When the connected screen is not 16:9 and no custom size is
  chosen, Full Screen fills the screen's real shape, the phone frames content the same
  way, and the edge shrink iOS applies to TVs is turned off so every dot is used.
- If a custom size is chosen and the screen offers exactly that size, the app switches
  the screen to it.
- Settings → Display Mode → Connected Screen shows the size being sent and the other
  sizes the screen offers.
- Ordinary 16:9 TVs and AirPlay are unchanged.

Apple TV: no change; not uploaded.

Sibling packages (same as 2026112203): eclipsepro 5eae5a2b (branch
claude/camera-frames-ribbon), CamTail ac076aa.

Tests: see the commit message for the count on this app commit and package code.
Not checked before upload: any odd-sized screen, real or simulated. Whether an iPhone
sends a non-standard size at all is what this build is for finding out, at the wall.
